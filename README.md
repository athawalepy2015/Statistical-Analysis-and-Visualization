🌌 Statistical Analysis & Geospatial Visualization of Light Pollution | Python, Pandas & Folium

Performed in-depth statistical analysis and visualization on the Globe at Night light pollution dataset to explore patterns in sky darkness measurements across time, geography, and population density. This project focuses on descriptive statistics, correlation analysis, and visual storytelling using both static and interactive plots.

The analysis examines relationships between SQM readings, limiting magnitude, cloud cover, location type, and Bortle sky classes. Geographic patterns are explored through interactive Folium maps, enabling spatial insight into regional and temporal variations in light pollution.

This project demonstrates applied skills in exploratory data analysis, statistical reasoning, data visualization, and geospatial analytics using Python.

Created bar charts, pie charts, and scatter plots to explore temporal and regional trends

Built interactive Folium maps to visualize global and regional light pollution patterns

Aggregated and filtered geospatial data for meaningful map-based insights
